# Profile

Every skill in this plugin reads this file. It is the only place your personal details live. The skills themselves contain no facts about you.

**How to fill it in:**
- Replace every `[bracketed]` placeholder. Delete the example text once you've written your own.
- Be exact with dates and titles. Copy them from your LinkedIn so the resume never contradicts it.
- If a section doesn't apply, write "N/A". An empty section makes the skills stop and ask you.
- This is your private copy. Don't commit a filled-in profile back to a shared repo.
